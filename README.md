## База данных

БД `DB_Pogulyaev_Security` состоит из трёх связанных таблиц:

- **Users** (ID, Login, Password, Role, FIO, Department, Photo) — пользователи системы;
- **ThreatCategories** (ID, Name) — категории угроз ИБ;
- **SecurityIncidents** (ID, ThreatCategoryID, UserID, Date, Name, Severity, Description, IPAddress, Status) — инциденты ИБ.

Связи «один-ко-многим»: `Users → SecurityIncidents`, `ThreatCategories → SecurityIncidents`.
Удаление каскадное (`ON DELETE CASCADE`). Скрипт с тестовыми данными — `db/schema.sql`.

**Тестовые учётные записи** (пароли хранятся в виде SHA1-хэша):

| Логин   | Пароль  | Роль  |
|---------|---------|-------|
| admin   | 123456  | Admin |
| ivanov  | user123 | User  |
| petrov  | user123 | User  |

## Реализованный функционал

- авторизация и регистрация пользователей с разграничением ролей (User / Admin);
- хэширование паролей (SHA1), капча после 3 неверных попыток входа
  (запрещено копирование/вставка текста капчи);
- смена пароля;
- роль «Пользователь»: просмотр сотрудников, поиск по ФИО, сортировка, фильтр «Только администраторы»;
- роль «Администратор»: добавление, редактирование, удаление (с подтверждением)
  во всех трёх таблицах, поиск и фильтрация инцидентов, диаграммы
  (выбор сотрудника и типа диаграммы), экспорт отчётов в Word, PDF и Excel;
- проверка формата вводимых данных (пароль: мин. 6 символов, английская раскладка,
  хотя бы одна цифра; IP-адрес по маске; ограничения по длине полей);
- плейсхолдеры и всплывающие подсказки для всех полей;
- динамический заголовок окна по содержимому страницы;
- подтверждение выхода из приложения и удаления данных;
- два словаря стилей (светлая тема по Руководству по стилю и собственная тёмная тема),
  смена темы кнопкой-списком в главном окне, выбранная тема сохраняется между сеансами.

## Запуск

1. Выполнить скрипт `db/schema.sql` в SQL Server Management Studio.
2. Открыть `UP01_Pogulyaev_Security.sln` в Visual Studio, восстановить NuGet-пакеты
   (EntityFramework, Microsoft.Office.Interop.Word, Microsoft.Office.Interop.Excel).
3. При необходимости изменить строку подключения в `App.config`
   (по умолчанию `(localdb)\MSSQLLocalDB`).
4. Запустить проект (F5).
