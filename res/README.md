# Ресурсы приложения

- `icon.ico` — значок приложения (подключается: Проект → Свойства → Приложение → Значок).
- `default_photo.png` — фотография по умолчанию для пользователей без фото
  (копируется в папку `images/` проекта с типом сборки Resource).

Графические файлы распространяются вместе с архивом проекта
(скачивание всего репозитория: Code → Download ZIP).
